## 1. Project Introduction

The **8TH FLOOR Hostel Grievance Management System** is a simple academic web application built for the Computer Programming subject. It uses a compiled **C Language Executable** as its backend logic layer and stores complaint records permanently using binary file handling (`complaints.dat`).

---

## 2. Objective

1. To demonstrate practical application of C programming concepts (Structures, Arrays, File Handling, Searching, Updating, Deleting).
2. To provide a simple interface for 8th Floor hostel residents to submit complaints.
3. To allow the Warden to review complaints, change statuses (Pending / Completed), and delete records.

---

## 3. Features

### A. Student Panel
1. **Student Login:** Enter Name, UID, and Room Number.
2. **Submit Grievance:** Select category and description.
3. **Complaint ID:** Unique ID generated by C backend.
4. **Complaint Tracker:** Search status by Complaint ID.

### B. Warden Panel
1. **Warden Login:** Username: `warden`, Password: `admin123`.
2. **View Complaints:** Live records loaded from `complaints.dat` via C backend.
3. **Status Update:** Toggle status between Pending and Completed.
4. **Delete Record:** Remove complaint from file.

---

## 4. Technologies Used

* **Frontend:** HTML, CSS, JavaScript (React).
* **Backend:** C Programming Language (`c_backend/main.c`).
* **Storage:** Binary File (`complaints.dat`).
* **Server:** Node.js, Express (`child_process.execFile` bridge).
* **Compiler:** GCC.

---

## 5. C Functions

```c
struct Complaint {
    int id;
    char studentName[50];
    char uid[20];
    char roomNo[15];
    char category[30];
    char description[300];
    char status[20];
};
```

* `addComplaint()`: Appends new struct to binary file.
* `viewComplaints()`: Reads structs into array and outputs JSON.
* `searchComplaint()`: Linear search by Complaint ID.
* `updateStatus()`: Rewinds file pointer with `fseek()` to update status.
* `deleteComplaint()`: Compacts file using temporary file write and rename.
